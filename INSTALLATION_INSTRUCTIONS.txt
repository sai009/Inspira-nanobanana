AI STORYBOARD PRODUCTION STUDIO - INSTALLATION GUIDE
=====================================================

This guide will help you set up the world's first complete AI-powered storyboard production studio that combines Gemini 2.5 Flash Image capabilities with ElevenLabs voice synthesis.

PREREQUISITES
-------------
- Python 3.8 or higher
- Git (for cloning the repository)
- Google AI API key (for Gemini 2.5 Flash)
- ElevenLabs API key (optional, for voice synthesis)

STEP 1: CLONE OR DOWNLOAD THE PROJECT
--------------------------------------
If using Git:
    git clone <your-repository-url>
    cd google-genai

If downloading as ZIP:
    - Extract the ZIP file to your desired location
    - Navigate to the extracted folder

STEP 2: CREATE A VIRTUAL ENVIRONMENT (RECOMMENDED)
---------------------------------------------------
Create a virtual environment to isolate dependencies:

On Windows:
    python -m venv venv
    venv\Scripts\activate

On macOS/Linux:
    python3 -m venv venv
    source venv/bin/activate

STEP 3: INSTALL DEPENDENCIES
-----------------------------
Install all required packages using pip:
    pip install -r requirements.txt

Or install packages individually:
    pip install gradio>=4.0.0
    pip install Pillow>=10.0.0
    pip install google-generativeai>=0.3.0
    pip install requests>=2.25.0
    pip install python-dotenv>=1.0.0

STEP 4: SET UP API KEYS
-----------------------
Create a .env file in the project root directory with your API keys:

1. Create .env file:
    touch .env    (on macOS/Linux)
    type nul > .env    (on Windows)

2. Add your API keys to .env:
    GOOGLE_API_KEY=your_google_ai_api_key_here
    ELEVENLABS_API_KEY=your_elevenlabs_api_key_here    (optional)

To get your API keys:
- Google AI API Key: Visit https://makersuite.google.com/app/apikey
- ElevenLabs API Key: Visit https://elevenlabs.io/app/speech-synthesis (optional)

STEP 5: RUN THE APPLICATION
---------------------------
Start the AI Storyboard Production Studio:
    python comprehensive_studio.py

The application will launch and provide a local URL (typically http://127.0.0.1:7860)
Open this URL in your web browser to access the studio.

FEATURES AVAILABLE
------------------
Once running, you can:
✅ Create and manage multiple projects
✅ Develop AI-powered characters with visual references
✅ Generate consistent character images
✅ Create scenes with multiple characters
✅ Build complete storyboards with audio
✅ Generate character-specific dialogue
✅ Export projects and storyboards
✅ Advanced image editing and expansion tools

TROUBLESHOOTING
---------------
1. If you get "Module not found" errors:
   - Ensure your virtual environment is activated
   - Reinstall requirements: pip install -r requirements.txt

2. If the application won't start:
   - Check that your API keys are correctly set in .env
   - Ensure Python version is 3.8 or higher: python --version

3. If image generation fails:
   - Verify your Google AI API key has image generation permissions
   - Check your API quota and usage limits

4. For scene selection errors when switching projects:
   - Click the "Refresh Scenes" button in the Storyboard Builder tab
   - This issue has been fixed in the latest version

5. If you encounter port conflicts:
   - The application will automatically find an available port
   - Check the terminal output for the correct URL

OPTIONAL ENHANCEMENTS
--------------------
For advanced audio features, uncomment and install:
    pip install pydub>=0.25.0
    pip install librosa>=0.8.0

SYSTEM REQUIREMENTS
-------------------
- RAM: Minimum 4GB, Recommended 8GB+
- Storage: At least 2GB free space for projects and generated content
- Internet: Required for AI API calls
- Browser: Modern web browser (Chrome, Firefox, Safari, Edge)

GETTING STARTED
---------------
1. Launch the application
2. Create a new project
3. Design characters in the Character Development tab
4. Generate character reference images
5. Create scenes with your characters
6. Build storyboards and add audio
7. Export your complete production

SUPPORT
-------
If you encounter issues:
- Check the terminal output for error messages
- Ensure all dependencies are properly installed
- Verify your API keys are valid and have sufficient quota
- Review the troubleshooting section above

Enjoy creating with the AI Storyboard Production Studio!
